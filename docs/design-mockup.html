File flow

Open, edit, save

  1. Open from Finder

    Use Open With, drag in a file, or press ⌘O.

  2. Start at the text

    The editor takes focus. Foldrest shows the detected language and lets you change it.

  3. Save to the same file

    Press ⌘S. If you close with edits pending, choose Save, Don’t Save, or Cancel.
